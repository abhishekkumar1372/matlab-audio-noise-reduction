# Real-Time Audio Noise Reduction System - MATLAB

A real-time audio noise-reduction project developed in MATLAB using digital signal processing techniques.

## Overview

This project applies digital filtering to suppress unwanted noise and improve audio signal quality. The system analyzes input signals in both the time and frequency domains and evaluates filtering performance using signal characteristics and signal-to-noise ratio (SNR).

## Features

- Real-time audio noise-reduction workflow
- Digital filtering for noise suppression
- Time-domain and frequency-domain signal analysis
- Signal-quality and SNR-based evaluation

## Tools

- MATLAB
- Digital Signal Processing (DSP)
